# backend-observability-service

A production-grade backend system designed to demonstrate real-world software engineering practices beyond basic CRUD applications.

This project focuses on building a scalable and observable API with:

- Structured logging with correlation IDs for request tracing
- Prometheus metrics for monitoring and performance insights
- Containerized infrastructure using Docker and Docker Compose (PostgreSQL + Redis)
- Integration testing with Testcontainers for reliable, isolated environments
- Automated CI/CD pipelines using GitHub Actions
- OpenAPI (Swagger) documentation for API clarity and usability
- Cloud deployment on AWS

The goal of this project is to simulate how modern backend systems are built, tested, monitored, and deployed in production environments.
